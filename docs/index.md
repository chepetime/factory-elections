# Factory documentation

This site renders the Markdown files in the repository `docs/` folder. Agents read the same files. Edit a file there, and the site shows the change.

- [Operations](operations/dev-server.md): start, restart, and stop the local app on main or in a worktree.
- [Docs app](operations/docs-app.md): run this site and add pages.
- [Tasks board](tasks-board.md): board tasks, keys, statuses and what each drop does.
- [Code map](harnes/CODE_MAP.md): find the package that owns a change.
- [Local backend](local-backend.md): RPC, health, shutdown, and recovery.
- [Worktrees](worktrees.md): create, run, and remove isolated checkouts.
